NHC Results

Result codes

FIN
Finished. Enter its time.
DNF
Did not finish: started but didn't finish.
RET
Retired from the race.
DNS
Did not start: came out but didn't start.
OCS
On course side: over the start line early and didn't go back.
DSQ
Disqualified.
DNC
Did not compete: didn't come out at all.

Only finishers' handicaps change. Every code except DNC still counts as having sailed this season.

Calculations follow the RYA NHC algorithm (May 2015) as described by HalSail.
